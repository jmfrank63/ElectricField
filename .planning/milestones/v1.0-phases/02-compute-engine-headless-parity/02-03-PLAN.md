## Phase Goal

**As the** developer, **I want to** have a cancellable threaded compute engine with headless SVG/PNG output, **so that** CI can verify every preset on all OSes without a display.

This plan delivers the headless-output half: any preset becomes an SVG and a PNG from the command line, with a parity oracle (committed expected counts) that CI will run in plan 02-04.
