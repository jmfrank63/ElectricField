# Roadmap - Milestone v2.5: Collections Flow, Grid Style, Charge Size & PDF Export

**Created:** 2026-10-12 (revised same day after the file-picker pivot)
**Status:** Executing
**Milestone goal:** As a user, I treat a collection as a document file I open from anywhere (Open Collection / Save Collection As through native file dialogs), open and save configurations from a grouped menu that greys out without a collection, read a light-green grid with an intersections-only mode, size charges from a dot to very large, and export to PDF (one configuration or a whole collection as pages).

## Phases

### Phase 1: Collections Flow, Grid/Size Options & PDF Export

**Goal:** All of the above, API-callable and session-persisted where applicable.
**Mode:** mvp
**Depends on**: -
**Requirements**: OPEN-01, CFG-04, GRID-05..06, SIZE-01, EXP-03
**Success Criteria** (what must be TRUE):

1. A collection is a document FILE: `Collections\<name>.ini` is the default home, but File > Open Collection... (Ctrl+O) opens any collection file from anywhere through the native picker, New Collection... and Save Collection As... save to a chosen path; the app starts with no collection open and auto-opens nothing; in an empty (no-tab) workspace after a UI-initiated switch the configuration chooser follows
2. Open Configuration... / Save Configuration / Save Configuration As... are grouped in the File menu; Save Configuration writes the active tab's charges back into its source configuration; every configuration entry is greyed out while no collection is open
3. Grid lines are light green; an Intersections checkbox above the Cartesian/Polar radios shows only the lattice points (Cartesian and polar) in a distinctly different colour; also `grid.set intersections on|off`, persisted per tab in the session
4. Charge size is a draw option: 2-120 px (dot to very large), default 25; settable in View > Options (Draw tab) and via `options.set charge-size`; persisted in options.ini; the physics hit radius is unchanged (parity preserved)
5. Export Configuration gains PDF (with PNG/SVG); Export Collection... renders every configuration of the collection into one PDF (one page each, names as bookmarks); both callable by path via `export.configuration` / `export.collection`
6. CI green on all three OSes plus TSan; smoke green; script suite updated and green; docs updated (api.md, README)

**Plans**: (single plan, executed inline in auto-mode)

## Notes

- Owner instruction: GSD auto-mode, always take the recommended answer (UAT gate auto-accepted and recorded).
- Design choices: the earlier in-app collection list chooser was replaced by native SDL file dialogs per the owner's pivot; per-collection sessions stay keyed by file STEM (Sessions\<stem>.ini); the collection file format is the v2 configuration store ([configuration "Name"] sections); the PDF writer is a font-free vector backend of the core Painter (one point == one device pixel, one page per renderScene); charge size changes the DRAWN radius only (DrawStyle.chargeRadiusPx), not the physics seed/hit radius (ComputeParams.chargeRadiusPx stays 25 for parity).
