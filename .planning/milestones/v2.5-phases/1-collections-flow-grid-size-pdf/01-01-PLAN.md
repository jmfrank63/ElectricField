# Plan 01-01: Collections Flow, Grid/Size Options & PDF Export

**Phase:** 1 - Collections Flow & Grid/Size Options
**Mode:** mvp (auto-mode; owner standing instruction: always take the recommended answer)

## Objective

Collections become document files (native Open/Save dialogs, any path), the File menu groups the
configuration actions with greyout while no collection is open, the grid gains a light-green lines +
intersections-only mode (checkbox above the geometry), charges get a user-adjustable drawn size, and
export gains PDF (one configuration, or a whole collection as one page per configuration).

## Deliverables

1. `PdfPainter` (src/core/ef/pdf.{hpp,cpp}): font-free vector PDF 1.4 backend of the core Painter
   (one renderScene = one page, titles as outline bookmarks, exact xref).
2. Collection file model in App: openCollectionFile/saveCollectionAsFile/createCollectionAt over any
   path, sessions keyed by file stem; the app starts with NO collection open; Close Collection leaves
   nothing open; API resolvers (bare name = Collections\<name>.ini, else path).
3. File menu regroup: configuration actions (New/Open/Save/Save As/Close) greyed without a
   collection; Save Configuration writes the active tab back to its source configuration
   (Tab::sourceConfig tracked by open/openUser/openRestored/save-as).
4. Native SDL file dialogs for Open Collection / New Collection / Save Collection As / Export
   Collection (shared exportStep machinery, kinds 1..3 + 10..13).
5. Grid: light-green lines (120,210,120), intersections-only dots (217,119,6) with bounded counts,
   an Intersections checkbox above the Cartesian/Polar radios, `grid.set intersections`, session
   field 8 (backward-compatible parse).
6. SIZE-01: chargeSize draw option 2-120 (options validate/serialize/parse, OptionsEdit, the Draw
   tab, `options.set charge-size`); physics radius untouched.
7. EXP-03: Export Configuration > PDF..., Export Collection... (fitted views, sync computes),
   `export.configuration` / `export.collection` commands; `--export` mode writes dipole.pdf too.
8. Tests/docs: PDF structure tests, charge-size tests, session 8-field test, script suite rewritten
   for the empty start (plus app.expect-no / app.expect-error), api.md + README.

## Verification

zig build (clean), zig build test (119+4 pass), zig build smoke, 5 script tests green, --export
writes dipole.pdf, path-form collection.open probe, full CI on all three OSes + TSan.
