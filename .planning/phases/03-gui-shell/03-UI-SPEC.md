# Phase 3 - UI Design Contract

> Visual and interaction contract for the GUI shell. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
> This is a native desktop app (Dear ImGui 1.92.9b immediate mode on SDL3 + sdlrenderer3), not a web app. There is no CSS,
> component library, Tailwind or shadcn. "px" means ImGui logical pixels (the units ImGui widgets and `ImDrawList` use);
> every metric below is declared at scale 1.0 and multiplied by the display scale `k` (see "HiDPI and scale contract").
> Locked decisions D-01..D-17 come from `03-CONTEXT.md` and are not re-asked. Values marked (default) are researcher choices.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none (no shadcn; not a React/Next/Vite project). Registry safety gate: not applicable |
| Preset | not applicable |
| Component library | Dear ImGui 1.92.9b-docking widgets only (MenuBar, TabBar, Modal popup, Selectable, Button, TextLink). Docking and multi-viewport stay OFF (D-01, STACK.md) |
| Style base | `ImGui::StyleColorsLight()` (D-08) plus the explicit overrides in this document; canvas is white regardless |
| Icon library | none. No icon font. The only imagery is the app icon (below). All glyphs are ASCII so the default font always has them |
| App icon | `ElectricField/res/ElectricField.ico` copied to `assets/ElectricField.ico` (D-14); window icon on all OSes from an embedded 256x256 image of the same artwork (`SDL_SetWindowIcon`); Windows exe icon via a resource file naming `assets/ElectricField.ico`. Conversion pipeline is the planner's choice |
| Font | Dear ImGui's embedded scalable font via `io.Fonts->AddFontDefaultVector()` (no new asset, no new licence; the repo is GPL-3.0 and ImGui is MIT). Rasterised at `FontSizeBase x k` using ImGui 1.92 dynamic fonts, so it stays crisp at any scale. Do NOT use `AddFontDefaultBitmap` (ProggyClean pixel font, soft when scaled). If the checker or the user later rejects its look, the pre-cleared substitute is DejaVu Sans (free licence, GPL-compatible) embedded as a C array; that is a swap of one call and not part of this phase |
| Persistence of layout | none. `io.IniFilename = nullptr` always (not only in smoke): the single host window is fixed, and window geometry/options persistence belongs to Phase 4 |
| Docking / viewports | `ConfigFlags_DockingEnable` and `ViewportsEnable` OFF. `ConfigFlags_NavEnableKeyboard` ON (Up/Down/Enter/Space/Tab work in menus and the chooser) |
| Mouse cursor | arrow normally; `ImGuiMouseCursor_Wait` (hourglass, parity with MFC `BeginWaitCursor`) while the pointer is over a busy tab's canvas; text widgets use the default. No custom cursors |

### Scene styling the canvas must use (single source: Phase 2 `ef::DrawStyle`, MFC `Options.cpp` defaults)

| Item | Value | Source |
|------|-------|--------|
| Canvas background | RGB(255,255,255) `#FFFFFF` | `DrawStyle::background`, MFC `Clear(White)` |
| Positive charge fill | RGB(0,0,255) `#0000FF` | `DrawStyle::positiveCharge` |
| Negative charge fill | RGB(255,0,0) `#FF0000` | `DrawStyle::negativeCharge` |
| Field line colour / thickness | RGB(0,0,0) `#000000`, 1.0 px x k | `electricLine`, `electricThickness` |
| Equipotential colour / thickness | RGB(192,192,192) `#C0C0C0`, 1.0 px x k | `potentialLine`, `potentialThickness` |
| Charge radius | 25 px x k (50 px diameter, matches the MFC baseline: charges measure about 50 px across at 100%) | `chargeRadiusPx` |
| World scale | 100 px per world unit x k, y up, origin at the canvas centre | D-06, `ef::View::pixelsPerUnit` |
| Draw order | field lines, then equipotentials, then charges | `renderScene` (do not reimplement) |
| Antialiasing | `ImDrawListFlags_AntiAliasedLines | AntiAliasedFill` ON, `style.AntiAliasedLinesUseTex = false`, `style.CurveTessellationTol = 0.3f` | D-05, Phase 2 PNG path |

The GUI draws the scene by constructing `efrender::ImGuiPainter(ImGui::GetWindowDrawList(), canvasTopLeft)` and calling
`ef::renderScene(painter, scene, style, view)` with `view = { widthPx = floor(canvas.x), heightPx = floor(canvas.y), pixelsPerUnit = 100 * k }`.
`style.electricThickness`, `style.potentialThickness` and `style.chargeRadiusPx` are multiplied by `k` before the call; the
colours are unchanged. `canvasTopLeft` is rounded to whole logical pixels so the 1 px lines stay aligned. No second drawing
path exists in the GUI (parity with `ef-cli` PNG is the acceptance bar).

## HiDPI and scale contract (D-07)

| Rule | Value |
|------|-------|
| Window flags | `SDL_WINDOW_RESIZABLE | SDL_WINDOW_HIGH_PIXEL_DENSITY` (as in the current hello window) |
| Scale factor `k` | `SDL_GetDisplayContentScale(SDL_GetDisplayForWindow(window))`, clamped to [0.75, 4.0], read at start and again on `SDL_EVENT_WINDOW_DISPLAY_SCALE_CHANGED` and `SDL_EVENT_WINDOW_DISPLAY_CHANGED` (the same scheme as the Dear ImGui SDL3 example). Windows per-monitor DPI: window units are physical pixels and `k` is e.g. 1.5 at 150%. macOS Retina: window units are points, `k` is 1.0, and the backend's framebuffer scale supplies the 2x sharpness |
| Applying `k` | keep a pristine `ImGuiStyle base` (light colours + the overrides below at scale 1). On every scale change: `style = base; style.ScaleAllSizes(k); style.FontScaleDpi = k;` and set `style.FontSizeBase = 16.0f` (sizes below come from `PushFont(nullptr, size)`; they are scaled by `FontScaleDpi` automatically). Never rebuild the font by hand. `CurveTessellationTol` and the AA flags are not scaled |
| Canvas | `pixelsPerUnit = 100 * k`, radius and thickness x k (above). The picture therefore has the same physical size as the UI text on every display, and 100 logical px per unit is sharp because ImGui coordinates are multiplied by the backend framebuffer scale at render time |
| Default window size | 1024 x 824 logical (canvas 1024 x 768 + 24 menu bar + 28 tab bar and separators) multiplied by `k`, then clamped to 90% of `SDL_GetDisplayUsableBounds`; centred on the primary display; minimum size 640 x 480 logical x k (`SDL_SetWindowMinimumSize`). Window and tab content are never smaller than the minimum |
| Resize | the origin stays at the centre of the canvas rect every frame; nothing is recomputed; larger canvas shows more white plane, smaller canvas clips (D-06). The ImGuiPainter clip rect does the clipping |
| Scale change while computing | no effect on sessions (they hold world-unit geometry); only the next frame's metrics change |
| Acceptance | on a 2x display the canvas picture is the same physical size as on a 1x display, with 1 px lines drawn at `1 x k` logical px (no blur, no half-width hairlines) |

## Spacing Scale

Declared values (multiples of 4), logical px at `k = 1`, set once in the base `ImGuiStyle`:

| Token | Value | ImGuiStyle field / usage |
|-------|-------|--------------------------|
| xs | 4px | `ItemInnerSpacing = (4,4)`, `FramePadding.y = 4`, `CellPadding = (4,4)`, spinner-to-text gap |
| sm | 8px | `FramePadding.x = 8`, `ItemSpacing = (8,4)`, `WindowPadding = (8,8)` for popups/modals, overlay panel padding |
| md | 16px | modal content margins (`WindowPadding = (16,16)` for the About and chooser modals), overlay inset from the canvas corner, `ScrollbarSize = 16`, `IndentSpacing = 16` |
| lg | 24px | row pitch of one frame (`FontSize 16 + 2 x FramePadding.y 4`): menu bar height, tab bar height, chooser row height, button height |
| xl | 32px | gap between the About title block and its body; chooser list to button row |
| 2xl | 48px | not used in this phase |
| 3xl | 64px | not used in this phase |

Layout rules:

| Surface | Rule |
|---------|------|
| Host window | one borderless ImGui window covering the whole SDL window (`GetMainViewport()->WorkPos/WorkSize`), flags `NoTitleBar | NoResize | NoMove | NoCollapse | NoSavedSettings | NoBringToFrontOnFocus | NoScrollbar | NoScrollWithMouse | MenuBar`; `WindowPadding = (0,0)`, `WindowBorderSize = 0`, `WindowRounding = 0` |
| Order | menu bar, then tab bar flush to the left/right edges, then the active tab's canvas |
| Focal anchor | The canvas scene (charges plus field lines and equipotentials, on the white 60% surface) is the primary focal anchor of the main screen; it takes all remaining area and the only saturated colours (blue/red charges). The menu bar and tab bar are secondary chrome in neutral greys and must never compete with it (accent is limited to the reserved list in Color) |
| Canvas | edge to edge: fills `ImGui::GetContentRegionAvail()` of the tab content with zero padding (MFC view was edge to edge, white). It is an `InvisibleButton` over the rect (so hover is known) with the scene drawn on the window draw list. No border, no rounding, no margin |
| Modals | centred in the viewport (`SetNextWindowPos(centre, Appearing, (0.5,0.5))`), not resizable, not collapsible, `AlwaysAutoResize` except where a width is fixed below |
| Style metrics | `WindowBorderSize = 0` host, `PopupBorderSize = 1`, `FrameBorderSize = 0`, `TabBarBorderSize = 1`, `TabBarOverlineSize = 0`, `WindowRounding = 0`, `FrameRounding = 4`, `PopupRounding = 4`, `TabRounding = 4` |

Exceptions: 1 px borders/separators (`PopupBorderSize`, `TabBarBorderSize`, overlay border) are not multiples of 4 by nature; the spinner stroke is 2 px; the
About modal width 400 and the chooser width 360 are multiples of 8 but are fixed content widths, not tokens. Desktop pointer UI: no 44 px touch targets apply; the
minimum interactive row is the 24 px frame row.

## Typography

One typeface (ImGui embedded vector font). Sizes are set with `ImGui::PushFont(nullptr, size)`; all are multiplied by `k` by `FontScaleDpi`.

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body (menu items, tab titles, chooser rows, buttons, empty-state text, busy overlay, About body and link labels) | 16px | Regular 400 | 1.5 (24px frame row; paragraph rows `ItemSpacing.y = 8` in About so wrapped lines pitch at 24) |
| Label (About version + commit hash line, shortcut hints in menus, About licence line) | 14px | Regular 400 | 1.5 (21px; use `ItemSpacing.y = 4` after it) |
| Heading (About app name "Electric Field", chooser heading none: chooser uses Body) | 20px | Regular 400 | 1.2 (24px) |
| Display | not used in this phase | - | - |

Weights: exactly one (Regular 400). The embedded ImGui font has no bold face, and a second weight would require shipping a TTF. Hierarchy comes from size
(20 / 16 / 14) and colour (below). This is a documented exception to the "2 weights" guideline, acceptable for a utility shell with three text roles.

Glyph policy: ImGui-rendered strings are ASCII only (the embedded font is only guaranteed for Basic Latin). So the "ellipsis" in labels is three ASCII dots
and the menu cascade is written ">" in prose; ImGui draws its own submenu arrows. The **SDL window title** is OS-rendered UTF-8 and uses the em dash exactly as D-15 states.

## Color

Chrome colours are the values `StyleColorsLight()` produces in Dear ImGui 1.92.9b (verified in `imgui_draw.cpp`), with three overrides. The canvas palette is locked by parity (see "Scene styling").

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#FFFFFF` canvas (scene background and `FrameBg`, `PopupBg` 98% white) | the canvas, popup and modal surfaces, list backgrounds |
| Secondary (30%) | `#F0F0F0` `WindowBg`; `#DBDBDB` `MenuBarBg`; tab strip from `ImGuiCol_Tab` (light blue-grey lerp, unchanged) | host window behind the tab bar, menu bar, unselected tabs, busy overlay panel (`#F0F0F0` at 90% alpha, RGBA 240,240,240,230) |
| Accent (10%) | `#4296FA` (ImGui light accent, `Header`/`ButtonHovered` family) | reserved list below |
| Destructive | not used for chrome (no destructive actions). Error text on a failed tab uses `#C00000` (contrast 7.5:1 on white) and appears only in that error state | session failure message |

Text colours: `ImGuiCol_Text = #000000` (17:1 on `#F0F0F0`). Muted text (empty-state hint, version line) = `#595959` (override of `ImGuiCol_TextDisabled`, which is `#999999` and fails 4.5:1 on `#F0F0F0`; this one is 6.6:1).

Overrides of the stock light style (the only ones): `ImGuiCol_TextDisabled = #595959`; `ImGuiCol_TextLink = #0054CC` (6.0:1 on `#F0F0F0`; stock `#4296FA` is 2.8:1); `ImGuiCol_ModalWindowDimBg = (0,0,0,0.25)` (a little darker so the dim is visible over the white canvas, stock 0.2/0.35 grey is nearly invisible on white).

Accent reserved for (never "all interactive elements"):

1. The selected tab (`ImGuiCol_TabSelected` family) and its focus underline.
2. The selected row in the preset chooser (`ImGuiCol_Header` / `HeaderActive`).
3. The default button of a modal ("Open Configuration" in the chooser, "Close About" in About) while hovered/active/focused, and keyboard-nav focus rectangles.
4. The busy spinner arc (tab-bar marker uses text colour, overlay spinner uses accent).
5. The hover highlight of menu items (`ImGuiCol_HeaderHovered`).

Charge blue/red are canvas data colours, never reused for chrome. Meaning is never colour-only in the chrome (busy state has a glyph and text). The charge sign itself is colour-only by parity with MFC; charge labels are deferred (VIEW2-04).

Busy overlay: panel `#F0F0F0` 90% alpha, 1 px border `(0,0,0,0.30)` (the stock `Border`), rounding 4, padding 8 (x) by 8 (y), text `#000000` Body 16px, spinner arc accent `#4296FA`, 270 degree arc, radius 8 px x k (16 px diameter = font size), stroke 2 px x k, one revolution per 1.0 s (`ImGui::GetTime()`), anchored at the canvas top-left inset 16 px x k. The overlay never overlaps the charges for any preset (charges are at most 3 units = 300 px from the centre horizontally and 150 px vertically, and the canvas default is 1024 x 768).

## Interaction Contract

### Keyboard

| Keys | Action | Condition |
|------|--------|-----------|
| Ctrl+N (Cmd+N) | open chooser | no modal open |
| Ctrl+W (Cmd+W) | close active tab | a tab exists and no modal open |
| Ctrl+Q (Cmd+Q) | quit | no modal open (Alt+F4 / window close always quits) |
| Ctrl+Tab / Ctrl+Shift+Tab | next / previous tab | ImGui built-in tab-bar behaviour; no custom code |
| Enter / Esc | chooser: Open Configuration / Close Chooser; About: Close About (both keys) | modal focused |
| Up / Down / Enter | chooser list navigation / activate | keyboard nav enabled |

Shortcuts use `ImGui::Shortcut(...)` evaluated once per frame in the host window, never while a text field is active (there are none in this phase).

### Mouse

| Gesture | Result |
|---------|--------|
| Click File / Help | menu opens; hover over File > New opens the preset submenu |
| Click a preset in File > New | opens that preset in a new tab immediately |
| Click tab / tab "x" | select / close the tab (instant, even if computing) |
| Middle-click tab | close the tab (ImGui default; keep enabled, do not set `NoCloseWithMiddleMouseButton`) |
| Drag tab | reorder inside the bar (no docking / tear-out, D-01) |
| Hover over a busy canvas | cursor `ImGuiMouseCursor_Wait`; over a finished canvas the normal arrow. Menu and tab bar are never covered by the wait cursor |
| Wheel / drag on the canvas | ignored (pan/zoom is v2) |

### Compute lifecycle

| Event | Contract |
|-------|----------|
| Open tab | creates the `ComputeSession` immediately with MFC default `ComputeParams` (4 threads, 16 lines per unit charge, Euler, equipotentials on, interval 0.10; D-09); charges are drawn at once, lines are not |
| While busy | each frame: `poll()` the session once; update n; draw charges + overlay; tab shows the marker; the wait cursor shows over the canvas. Lines are NOT drawn progressively (D-10, parity) |
| Done | on `status.done && !failed && !cancelled`: `takeResult()` -> `buildScene` once -> cache the `FieldScene` in the tab; marker and overlay disappear on that frame; the cached scene is re-rendered each drawn frame (no recompute) |
| Failed | `status.failed`: show the failure copy above; never crash, never block |
| Close tab (busy or not) | call `cancel()` then destroy the session (RAII join), remove the tab; the UI stalls for at most the 200 ms contract |
| Quit | on `SDL_EVENT_QUIT` or File > Exit: call `cancel()` on every session first (so waits overlap), then destroy them all, then `ImGui_ImplSDLRenderer3_Shutdown`, `ImGui_ImplSDL3_Shutdown`, `ImGui::DestroyContext`, `SDL_DestroyRenderer`, `SDL_DestroyWindow`, `SDL_Quit`; no dialog (D-11). Sessions are destroyed before SDL/ImGui teardown |
| Resize / minimise | resize re-lays out only; minimised or occluded windows skip rendering but sessions keep being polled |
| Scale change | see HiDPI contract |
| Startup error paths | check every init return (`SDL_Init`, `SDL_CreateWindow`, `SDL_CreateRenderer`, `ImGui_ImplSDL3_InitForSDLRenderer`, `ImGui_ImplSDLRenderer3_Init`), release whatever was created in reverse order, show the fatal error copy, exit 1 (fixes review WR-02 class of leaks) |
| UI-thread rule | `efrender::renderPng` is never called from the GUI loop in this phase; if added later it runs on the UI thread between frames (D-17) |

### Main loop (D-12)

| State | Behaviour |
|-------|-----------|
| Renderer | `SDL_SetRenderVSync(renderer, 1)` after creation; the result is not fatal if unsupported (then cap the loop with `SDL_Delay(16)`) |
| Idle (no tab computing, no animation in flight) | block in `SDL_WaitEventTimeout(&e, 250)`; after any event or timeout drain with `SDL_PollEvent`, then render. Render at least 3 frames after each input event (ImGui needs extra frames for hover, focus and popup open/close to settle). No busy loop, no 100% CPU while idle |
| Any session computing | `SDL_PollEvent` each frame, render every vsync frame (about 60 fps; never more), poll every session once per frame. The spinner animation is the reason frames continue |
| Smoke mode (D-16) | see below; the idle wait path is also exercised because tabs finish before the end |

### Smoke mode (D-16)

`ef-gui --smoke` (software renderer, dummy video driver, `io.IniFilename = nullptr`, no startup chooser, no input):

1. Print `video=<driver> renderer=<name> presets=9`.
2. Open "Four Charges Same Sign" and close it again within the first two frames (exercises cancel of a busy session). Then open "Dipole" and run the normal loop until its session is done (poll once per frame, short `SDL_Delay` allowed, hard timeout 60 s -> print error, exit 1), then render at least one frame that draws the finished scene through `renderScene`/`ImGuiPainter`, then close the tab.
3. Also render one frame with the empty state, one with the About modal open and one with the chooser open (Esc-less: just call the open path), so every UI surface executes.
4. Shut down cleanly in the order above. Print one final line `smoke ok frames=<N> tabs_opened=2 lines=<field_lines> closed=2`, exit 0. Any failure exits non-zero. The smoke path must still not write `imgui.ini`.
