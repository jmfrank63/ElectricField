# Phase 261012-h23 Plan 01: Add a charge size control Summary

The Options Draw tab's Charge size field now steppers with +/- buttons like every other numeric field in the dialog, and the control is proven at all three test layers: OptionsEdit doctest contract, GUI smoke apply/restore, and a `drawsize=` script oracle exercised end-to-end by the new 15-options.efscript.

## What Was Built

- **Steppers (src/gui/ui.cpp:553):** the Charge size InputDouble carries step 1.0 / step_fast 10.0 (was 0.0/0.0, which disabled the +/- buttons). The `"%.0f"` format and the `Charge size 2 - 120, thicknesses 1 - 64` hint are unchanged. Stepped-past-range values are correct behavior: OK routes through `OptionsEdit::validate()` which rejects out-of-range without clamping (D-04).
- **Smoke proof (src/gui/app.cpp Options block):** the apply block sets `e.chargeSize = 60` beside `electricThickness = 4` and asserts `options_.draw.chargeRadiusPx == 60.f` after the dialog's apply path; the defaults-restore block asserts `25.f` is back. Smoke reports `options=ok`.
- **OptionsEdit contract (tests/test_options.cpp):** new TEST_CASE "OptionsEdit chargeSize: edges rejected without clamping, reset copies, apply converts (SIZE-01)" — 1.9 and 121 → `validate()` false with a non-empty error; 2 and 120 → validate true and `apply().draw.chargeRadiusPx == 2.f / 120.f` exactly; a custom 60.f Options → reset copies (`doctest::Approx(60.0)`) and `apply() == custom` via the operator== that already covers the field.
- **Script oracle (src/gui/app.cpp app.state builder):** `drawsize=<px>` emitted directly after `configs=`, reading `options_.draw.chargeRadiusPx`. Additive — no existing assertion touches the line.
- **15-options.efscript (new, picked up by the ci.yml:93 glob):** collection.open Original / config.open Dipole / app.wait-done openers; `app.expect drawsize=25` on a fresh sandbox; `options.set charge-size 60` → `drawsize=60`; refusals of 121 and 1 via `app.expect-error "2..120"` with `drawsize=60` unchanged after; boundaries 2 and 120 accepted and observable; `app.quit force`.
- **docs/api.md:** the state-oracle sample gains `drawsize=25` after `configs=My Field`, plus one explanation line: `drawsize=` is the drawn charge radius in px (v2.5 SIZE-01, valid range 2-120; the `chargeSize` key in options.ini).
